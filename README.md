# Sistema de Recomendação de filmes
Recomendador de filmes usando técnicas de aprendizado de máquina e filtragem colaborativa.

Este projeto foi desenvolvido como projeto de extensão universitária. A estrutura teórica de filtragem colaborativa foi adaptada do curso de Machine Learning da DeepLearning.AI / Prof. Andrew Ng. O dataset utilizado, por sua vez, corresponde ao dataset do MovieLens para fins educativos. A arquitetura de inferência em tempo real em NumPy, a localização para o português e a interface web interativa em Streamlit foram implementadas pelo autor do projeto.
